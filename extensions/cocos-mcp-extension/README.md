# Packaged Cocos MCP Extension

Copy this folder into your Cocos Creator project's `extensions/` directory.

Contents:
- `package.json`
- `dist/`
- bundled runtime dependency at `node_modules/@cocos-mcp/shared`

After copying:
1. Restart or refresh Cocos Creator
2. Verify the extension loads
3. Call the `start-server` extension message or rely on `load()` auto-start

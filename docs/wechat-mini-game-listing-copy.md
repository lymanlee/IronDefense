# 微信小游戏上架文案整理

适用场景：微信小游戏提审资料、产品简介、发行沟通、渠道展示页文案  
说明：以下内容基于当前项目实际实现整理，个别名称可按最终发行命名替换。

## 一、产品概述

《桥防守卫》（暂定名）是一款竖屏轻度动作射击小游戏。玩家将驾驶武装战车驻守废土公路防线，在持续推进的敌潮中左右机动、自动开火，抵御不同类型的装甲敌人与首领单位。游戏以“即时战斗爽感 + 局内补给构筑 + 局外成长养成”为核心，兼顾上手门槛与中短局策略深度。

整体节奏明快，单局体验聚焦于“防线守住、火力堆高、关键时机拿补给”的连续战斗反馈，适合微信小游戏用户碎片化游玩。

## 二、游戏主界面风格

### 1. 视觉基调

游戏整体采用 `废土机甲` 风格，核心视觉关键词为：

- 荒漠公路
- 工业废墟
- 装甲钢板
- 警示黄与灼热橙
- 战损机械与火力压制

主色调以深棕、钢灰、沙土色为底，辅以橙黄高亮和少量警示红，强化“战场警戒感”和“重装火力感”。整体画面避免过度写实，强调移动端小游戏所需的清晰辨识度与直接冲击力。

### 2. 首页氛围

首页以废土公路主视觉作为背景，配合战车主形象、关卡卡片和金属功能面板，突出“进入战斗前整备”的临场感。按钮、卡片和信息栏统一采用工业化装甲面板语言，保证首页、车库页和战斗页在风格上保持一致。

### 3. 战斗界面表现

战斗界面采用竖屏俯视防守视角，玩家位于画面下方防线区域，敌人自上方持续压进。HUD 信息区以半透明金属面板承载生命、波次、进度和增益信息，既保证信息清晰，也不会遮挡战斗主体。子弹、爆炸、电弧、护盾等特效偏暖色高冲击风格，便于在高强度战斗中快速识别火力成长变化。

## 三、整体玩法设计

### 1. 核心玩法

玩家通过左右滑动控制武装战车在桥面/公路防线横向移动，战车会自动持续开火。玩家需要在有限的防守空间内处理不同敌人带来的推进压力，避免敌人突破护栏并消耗战车耐久。

游戏采用“关卡 + 波次”的战斗结构。每个关卡由多波敌人组成，敌人会随着波次推进逐步增强，并引入高速、护盾、自爆、治疗和首领等不同类型单位，形成越来越强的压迫感。

### 2. 核心循环

游戏的主要循环为：

1. 玩家在首页选择关卡并进入战斗
2. 驾驶战车进行横向走位并自动射击
3. 清理敌潮、维持防线、推进波次进度
4. 击毁战斗中刷新的补给宝箱，触发补给选择
5. 从多张补给卡中选择本关增益，形成当前局内构筑
6. 完成关卡后获得金币、零件等奖励
7. 回到车库升级永久能力，准备下一局挑战

这一结构兼顾了即时反馈和持续成长，既能满足短局快玩的爽感，也能提供反复挑战和资源积累的长期目标。

### 3. 策略深度

虽然操作方式简洁，但战斗过程中仍具备明确决策点：

- 什么时候优先清理前线敌人
- 什么时候切火力去击毁补给宝箱
- 本关优先选择输出、生存还是控制类补给
- 是否通过广告换取额外补给或复活机会
- 结算后的资源优先投入哪条永久成长路线

因此，游戏在“轻操作”基础上保留了足够的构筑和成长策略空间。

## 四、系统功能描述

### 1. 关卡与波次系统

游戏当前采用关卡制推进，每个关卡由多波敌人构成。波次内容会按节奏逐渐升级，并在后期引入高压混合敌潮与 Boss 单位，强化阶段目标与通关成就感。

关卡系统的主要作用包括：

- 承载玩家的挑战进度
- 定义每局的波次数量和敌人强度
- 提供通关奖励与阶段性目标
- 支撑后续章节化扩展

### 2. 战斗控制系统

战斗操作以单手体验为主，适配微信小游戏碎片化场景：

- 左右滑动控制战车横向移动
- 武器自动射击，降低操作门槛
- 通过走位和火力构筑应对敌潮压力

这种设计保证了新玩家易上手，同时也能让高频战斗更流畅。

### 3. 敌人系统

游戏内包含多类敌人单位，不同敌人承担不同战场职能：

- 普通敌人：基础推进单位，形成持续消耗压力
- 高速敌人：快速贴近防线，考验应急处理能力
- 护盾敌人：生存能力更强，要求更高持续火力
- 自爆敌人：高风险近身威胁，逼迫玩家提前清除
- 治疗敌人：为敌群提供恢复支持，提升波次复杂度
- Boss 单位：高耐久、高压迫感的阶段性挑战目标

多类型敌人混合出现，使每一波战斗都具备不同应对方式。

### 4. 武器成长系统

游戏的武器成长分为“基础火力档位”和“局内流派强化”两层：

- 基础火力档位：决定战车开局的基础射速、伤害、并发和连发能力
- 局内流派强化：通过补给卡在当前关卡内不断叠加，形成不同战斗风格

当前支持的武器演化方向包括：

- 爆裂：适合清理密集敌群
- 穿透：适合打穿纵向敌列
- 电弧：适合连锁压制高速或辅助型敌人

该系统让每一局都能形成不同的输出构筑，提升重复游玩的差异化体验。

### 5. 补给宝箱与道具系统

补给系统是游戏局内策略的重要组成部分。战斗过程中会随机刷新不同品质的补给宝箱，玩家击毁后可获得补给选择机会。补给效果仅在当前关卡内生效，通关或失败后重置。

补给内容主要分为两大类：

- 火力类补给：提升伤害、射速、弹速、并发、连发、爆裂范围、穿透次数、电弧数量等
- 控制类补给：提供护盾、冻结、震荡、清场、空袭等即时战术效果

补给宝箱具备品质区分，包括：

- 普通补给
- 精英补给
- 稀有补给
- 传说补给

品质越高，出现高星级补给的概率越高。该系统同时强化了“战斗中抢资源”的临场决策感。

### 6. 货币系统

当前游戏采用双货币结构：

- 金币：主要通过击杀、波次推进和关卡结算获得，用于常规永久升级
- 零件：主要通过关卡通关与结算获得，用于更稀缺、更关键的成长项升级

双货币设计有助于区分“基础养成”和“关键成长”两条资源线，让玩家在局外养成中形成更明确的投入选择。

### 7. 车库永久升级系统

玩家可在车库界面使用金币或零件对战车进行永久强化。当前永久升级方向包括：

- 复合装甲：提升最大耐久
- 穿甲弹芯：提升基础伤害
- 火控核心：提升开局基础武器档位
- 战备基金：提高每局金币收益
- 应急护盾：强化复活后的恢复与保护效果
- 军需协定：提高高品质补给出现概率
- 回收机械臂：提高每局零件收益

该系统为玩家提供持续成长目标，增强长期留存动力。

### 8. 结算奖励系统

每局结束后，系统会根据玩家表现发放结算奖励，奖励来源包括：

- 击杀收益
- 波次推进收益
- 关卡通关奖励
- 部分成长项带来的额外收益加成

结算奖励直接进入长期养成体系，形成“战斗 - 奖励 - 升级 - 再挑战”的闭环。

### 9. 复活与激励广告系统

游戏内接入了轻量激励广告机制，用于提升容错和转化空间，当前主要包括：

- 失败后观看广告复活一次
- 补给选择时观看广告刷新或追加补给机会
- 结算时观看广告领取双倍奖励

该设计在不破坏核心战斗节奏的前提下，为玩家提供更多补救与增益选择。

### 10. 存档与进度保留系统

游戏支持本地进度保存，玩家的关键成长内容可持续保留，包括：

- 金币与零件数量
- 车库永久升级等级
- 当前关卡进度与解锁状态

该系统保证了微信小游戏用户在多次短局游玩之间的连续成长体验。

## 五、可用于提审或介绍页的精简版文案

### 1. 一句话介绍

驾驶武装战车死守废土防线，在敌潮压境中抢夺补给、构筑火力，完成一场场高压又爽快的竖屏防守射击战斗。

### 2. 短版玩法介绍

这是一款竖屏轻度动作射击小游戏。玩家通过左右滑动控制战车走位，自动开火抵御不断逼近的敌人，并在战斗中击毁补给宝箱、选择本关强化路线。局内通过补给构筑爆裂、穿透、电弧等不同火力流派，局外通过金币和零件升级战车属性与开局火力，持续挑战更高强度关卡。

### 3. 系统亮点概述

- 竖屏单手操作，战斗节奏直接
- 废土机甲风格鲜明，视觉辨识度高
- 局内补给构筑与局外车库养成并行
- 多类型敌人与 Boss 设计提升挑战变化
- 激励广告点位清晰，兼顾体验与转化

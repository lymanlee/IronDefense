# 数值基线报告

更新时间：2026-06-25

## 一、报告目的

这份报告记录当前 `tools/balance/` 离线模拟器与当前 `GameConfig.ts` 对齐后的最新基线结果，用于判断前中期节奏、首个补给窗口和成长释放是否健康。

当前结论用于指导下一轮数值收口，不代表已经达到最终上线数值。

## 二、当前模拟范围

当前模拟器已经覆盖以下关键链路：

- `GameConfig.ts` 作为唯一数值源
- 敌人按 `waveDefs.entries + mixMode + spawnInterval` 分批生成
- 敌人推进到护栏后才开始按攻击频率造成伤害
- 玩家按 `fireRate` 触发开火，并计入并发与连发
- 宝箱从 `minWave` 开始生成，并受 `baseSpawnDelay / refillDelay` 限制
- 玩家打箱会真实占用火力，不再与清怪并行白嫖输出
- 补给卡收益跨波保留
- 波间 `pauseTime / wavePauseTime` 已计入总节奏

当前仍未完全对齐的部分：

- 更精细的多弹道命中空间分配
- 宝箱轨道与敌军轨道的真实空间博弈
- 控制类补给卡的即时战术价值
- 更高档位武器分支在真实战场中的溢出收益

## 三、当前配置状态

这一轮已经落地的关键调整：

- 下调了 `waves[1..4]` 的基础 `hp / speed / atk`
- 重写了前 6 波的编排密度，尤其压低了第 1 到第 4 波的总兵力与装甲占比
- 将首个宝箱窗口保留在第 3 波，但延后 `baseSpawnDelay`
- 大幅拉长 `refillDelay`，避免同一波连续刷出过多宝箱
- 下调前中期 `chestHpMultiplierByWave` 与 `baseHpFactor`
- 保留 `minChestSerialToOffer = 3`，避免过早放出分支进化

当前设计意图很明确：

- 第 1 波只承担教学与熟悉打箱意识，不应拉太长
- 第 3 波给第一个成长窗口，但不允许连续吃满多箱
- 第 4 到第 5 波开始承担真实筛选压力

## 四、批量基线结果

批量样本：

- `seeds = [1, 2, 3, 4, 5]`
- `strategies = ['conservative', 'balanced', 'expert']`
- `startTier = 1`
- `stageIndex = 0`

汇总结果：

- `clearRate = 13.3%`
- `avgWaveTime = 46.07s`
- `avgPlayerHpPct = 79.3%`
- `chestDestroyRate = 84.2%`
- `firstEvolutionWave = 0.73`
- `snowballIndex = 0.85`

直接结论：

- 当前版本已经不再是“前两波劝退”
- 绝大多数样本都能稳定通过第 1 到第 3 波
- 主要失败点已后移到第 4 到第 5 波
- 少量 seed 已能通关，说明数值链路已经具备闭环，但稳定性还不够

## 五、单局观察

### 5.1 稳定通过区间

在当前基线下：

- 第 1 波稳定通过
- 第 2 波稳定通过
- 第 3 波稳定通过

典型表现：

- 第 1 波时长约 `45.5s`
- 第 2 波时长约 `21.4s`
- 第 3 波时长约 `28.4s`
- 第 3 波通常只生成 `1` 个宝箱，并且可被稳定击毁

这说明首个成长窗口已经基本合理，不再与第 2 波直接冲突。

### 5.2 当前主要卡点

当前主要失败区间为：

- 第 4 波
- 第 5 波

批量失败分布：

- 第 4 波失败：`9 / 15`
- 第 5 波失败：`4 / 15`
- 成功通关：`2 / 15`

说明：

- 当前前期已经从“开局劝退”切换成“中前段开始分层”
- 这是正确方向，但第 4 波到第 5 波的密度与补给收益之间仍有波动

### 5.3 宝箱与成长释放

当前宝箱侧的几个信号：

- `chestDestroyRate = 84.2%`
- 第 3 波通常是 `1/1`
- 第 4 波可能出现 `3/3` 或 `3/4`

说明：

- 首箱已经不是问题
- 第 4 波开始，部分样本会再次出现“打箱过多导致清怪压力上升”的现象
- 当前的主要矛盾已经从“首箱太难”转成“中前段补给释放过快时，会开始分化出强弱局”

## 六、当前最明显的失衡点

### 6.1 第 4 波仍偏长

当前第 4 波在部分样本中会被拖到 `60s+`。

直接后果：

- 场上宝箱补位次数变多
- 玩家更容易把火力分流到宝箱
- 敌方压力与补给收益在同一波内叠加，导致局势波动变大

### 6.2 第 5 波压力跳变偏硬

当前不少样本能过第 4 波，但会在第 5 波迅速失败。

这说明：

- 第 4 波结束时虽然拿到了成长
- 但第 5 波的敌军结构与密度仍然偏陡
- 当前成长释放对第 5 波的覆盖还不够稳定

### 6.3 分支进化仍偏晚

`firstEvolutionWave` 的批量均值只有 `0.73`，本质上表示大多数局还没稳定拿到分支卡就已经失败。

这意味着：

- 当前版本已经解决了“首箱冲突”
- 但还没有真正进入“分支玩法稳定展开”的区间

## 七、建议的下一轮调优方向

下一轮不建议回头再动第 1 到第 3 波，重点只看以下三类参数：

- `waveDefs[3] ~ waveDefs[5]`
- `stages[0].chestHpMultiplierByWave[3..5]`
- `gameplay.supply.chest.refillDelay`

建议方向：

- 继续压缩第 4 波总时长，避免同波刷出过多补给
- 将第 5 波压力做得更连续，而不是突然跳变
- 保持第 3 波首箱健康，不再提前宝箱或提前分支

## 八、当前结论

当前这版数值已经完成了第一阶段目标：

- 不再在第 2 波前后劝退新玩家
- 首个宝箱窗口已经从“冲突源”变成“正常成长入口”
- 主要决策压力已后移到第 4 到第 5 波

当前最需要继续优化的，不是开局，而是：

- 第 4 波的持续时长
- 第 5 波的压力斜率
- 中前段补给释放节奏的稳定性

也就是说，下一轮调优应该进入“中段稳定性优化”，而不是继续做“前期减压”。
